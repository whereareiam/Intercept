# Security Policy

Intercept rewrites what players read and stores what a network's admins publish, so a flaw in it can put text in front of players that nobody wrote, or let a player change what others see.

## Supported versions

Security fixes go into the next release built from `dev`. Only the latest release receives them; update to it before reporting.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/whereareiam/Intercept/security/advisories/new). Do not open a public issue, pull request, or Discord message with the details.

Include:

- the Intercept version, the server or proxy, and the database or replication setup
- what an attacker can do, and what they need for it
- steps to reproduce

You receive an answer on the report. The fix is released before the details are published, and the release notes name it as a security fix.
