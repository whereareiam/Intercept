<Setting name="type" depth={2} takes="`SQLITE`, `H2`, `MYSQL` or `POSTGRES`" default="`SQLITE`" affects="where Intercept stores the network's messages and players' languages">

`SQLITE` and `H2` are files of one server. A network needs `MYSQL` (MySQL or MariaDB) or `POSTGRES`, shared by every
server.

</Setting>

</Setting>

</Setting>

<Setting name="port" depth={2} takes="a port" default="`5432`" affects="the database server's port; MySQL uses `3306`">
</Setting>

<Setting name="database" depth={2} takes="a name" default="`intercept`" affects="the database Intercept creates its tables in">
</Setting>

<Setting name="username" depth={2} takes="a name" default="`intercept`" affects="the user Intercept connects as">
</Setting>

<Setting name="password" depth={2} takes="a password" default='`""`' affects="the user's password" flag="warning">
</Setting>
