<Setting name="instance" depth={2} takes="a string" default='`""`, a random name on each start' affects="the name of this server in Intercept's logs and replication">

Give each server of a network its own name.

</Setting>

<Setting name="defaultLanguage" depth={2} takes="a language tag" default="`en`" affects="the language of a text that has none in the player's language">
</Setting>

<Setting name="languages" depth={2} takes="a list of language tags" default="`[en]`" affects="the languages players can choose with `/language`, and the remote bundles that are downloaded">
</Setting>

<Setting name="revisionPoll" depth={2} takes="a duration" default='`"30s"`' affects="how often a server checks the database for messages another server published">

With Redis, publications arrive at once and polling only catches what Redis missed.

</Setting>

<Setting name="remote.enabled" depth={2} takes="`true` or `false`" default="`false`" affects="whether translation bundles are downloaded">

Remote bundles are semantica bundles served over HTTP, such as the ones an organisation's translations repository
builds. Their texts win over Intercept's and the plugins' own texts and lose to `messages/` and `local/messages/`.
Intercept keeps them off, with a warning, while `url` or `product` is empty.

</Setting>

<Setting name="remote.url" depth={2} takes="a URL" default="empty" affects="where the bundles and their `manifest.json` are">
</Setting>

<Setting name="remote.product" depth={2} takes="a string" default="empty" affects="whose bundles this server uses, such as the name of its game mode">

Each product has one bundle per language, `<product>/<language>.json`.

</Setting>

<Setting name="remote.prefixes" depth={2} takes="a list of key prefixes" default="`[]`, all of them" affects="which keys of the bundles are kept, such as `game` or `lobby`">

A prefix matches whole key segments: `game` keeps `game.menu.title`, not `gamemode.title`.

</Setting>

<Setting name="remote.interval" depth={2} takes="a duration" default='`"5m"`' affects="how often to look for new bundles">

The last downloaded bundles are kept in `cache/remote/`, so a server starts with them when the address cannot be
reached.

</Setting>
