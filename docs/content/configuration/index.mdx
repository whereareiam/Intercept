title: Overview
description: Intercept's files and what each one holds.
---

Intercept writes its files on the first start and adds settings that a newer version introduces, keeping what you
changed.

| File | Holds |
| --- | --- |
| [`settings.yml`](./settings/index.mdx) | languages, the organisation's translations, this instance's name |
| [`commands.yml`](./commands/index.mdx) | names, aliases and permissions of the commands |
| [`interception.yml`](./interception/index.mdx) | which system messages are translated, and the marker |
| [`rules/*.yml`](./rules/index.mdx) | rules that translate other plugins' messages |
| [`persistence.yml`](./persistence/index.mdx) | the database |
| [`replication.yml`](./replication/index.mdx) | Redis |

The folders `messages/`, `rules/` and `local/` hold texts and rules; [Changing messages](../admins/guides/messages/index.md)
explains them.
