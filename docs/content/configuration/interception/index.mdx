---
title: interception.yml
description: Every setting of interception.yml.
---

The file has a section for each kind of message from the server: `chat`, `actionBar` (above the hotbar) and
`kick` (the reason a player is kicked or cannot join). Signed player chat is never changed.
[Translating other plugins](../../admins/guides/interception/index.md) explains markers and rules.

```yaml
chat:
  enabled: true
  marker: "<lang>"
  rules: true
actionBar:
  enabled: true
  marker: "<lang>"
  rules: true
kick:
  enabled: true
  marker: "<lang>"
  rules: true
```

Each section has these settings:

<Setting name="enabled" depth={3} takes="`true` or `false`" default="`true`" affects="whether this kind of message is translated">
</Setting>

<Setting name="marker" depth={3} takes="an opening, a name and a closing" default='`"<lang>"`' affects="what a marker looks like, such as `<lang key=...>` or `[t key=...]` for `[t]`">
</Setting>

<Setting name="rules" depth={3} takes="`true` or `false`" default="`true`" affects="whether rules apply to this kind of message">
</Setting>
